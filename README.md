# Максим + Полина

Статичный сайт свадебного приглашения для GitHub Pages.

## Как публиковать

В настройках репозитория GitHub Pages выберите:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/root`

После этого сайт будет доступен по адресу:

`https://andreykrnsov.github.io/maksim-and-apolinary/`

## Именные ссылки

На обычной странице без параметра гостя есть блок «Создать именную ссылку».
Гости, которые открывают ссылку с `?guest=...`, этот блок не видят.

Пример готовой ссылки:

`https://andreykrnsov.github.io/maksim-and-apolinary/?guest=Иван%20и%20Софья#invite`

Также можно вручную использовать параметры `guest`, `guests` или `to`.

## Анкета

GitHub Pages не принимает формы на своей стороне. Без дополнительной настройки анкета:

- проверяет обязательные поля;
- сохраняет последний ответ в браузере гостя;
- формирует готовый текст ответа для копирования или отправки через системное меню.

## Подключение Google Forms

Вся настройка вынесена в `rsvp-config.js`. Основной `script.js` менять не нужно.

1. Создайте Google Form с такими вопросами:
   - `ФИО`: короткий ответ, обязательный.
   - `Будете ли вы присутствовать на свадьбе?`: один вариант, обязательный.
     Варианты: `Да, будем`, `К сожалению, не получится`.
   - `Вы останетесь с ночевой?`: один вариант, обязательный.
     Варианты: `Да`, `Нет`, `Пока не знаем`.
   - `Есть ли предпочтения по алкоголю`: абзац, необязательный.
   - `Трансфер в г. Воткинск`: один вариант, обязательный.
     Варианты: `Нужен`, `Не нужен`, `Пока не знаем`.
   - `Для приглашения`: короткий ответ, необязательный.
   - `Отправлено`: короткий ответ, необязательный.
2. В Google Forms откройте вкладку `Ответы` и включите таблицу Google Sheets, если хотите видеть все ответы в таблице.
3. Там же в меню с тремя точками можно включить уведомления о новых ответах на почту.
4. В форме нажмите `Отправить`, скопируйте ссылку и откройте ее в браузере.
5. Откройте исходный код страницы формы. Проще всего: правый клик, `View page source`.
6. Найдите `formResponse`. Полный адрес вида
   `https://docs.google.com/forms/d/e/.../formResponse` вставьте в `googleFormAction` в `rsvp-config.js`.
7. В исходном коде рядом с каждым вопросом найдите его `entry.123456789`.
8. Вставьте эти значения в `googleFormFields` в `rsvp-config.js`, например:

```js
window.RSVP_CONFIG = {
  endpoint: "",
  googleFormAction: "https://docs.google.com/forms/d/e/FORM_ID/formResponse",
  googleFormFields: {
    guestName: "entry.111111111",
    attendance: "entry.222222222",
    overnight: "entry.333333333",
    alcohol: "entry.444444444",
    transfer: "entry.555555555",
    invitationFor: "entry.666666666",
    submittedAt: "entry.777777777",
  },
};
```

После этого ответы с формы на сайте будут уходить в Google Form, а в Google Forms
можно открыть вкладку `Ответы` и привязать таблицу Google Sheets.

Важно: порядок `entry.*` зависит от конкретной Google Form. Если поменять или
пересоздать вопрос, его `entry.*` может измениться.
